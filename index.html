Why was this created?

I love cross stitching and wanted a simple way to model out pixel art fonts for small projects.

Pixel-text lets me quickly visualize text layouts before stitching, no more second guessing myself!

Release Notes

v1.4
Changelog, responsive design & canvas interaction
2026-05-09
  • Added Release Notes modal (this menu) accessible via the version badge.
  • Added responsive mobile layout — sidebar stacks above canvas at narrow widths.
  • Added canvas pan via left- or right-click drag, with a recenter button that fades in when the view is offset.
  • Added two-finger pinch-to-zoom on touch devices.
  • Added Reset button that appears in the Input Text header whenever sliders deviate from defaults.
  • Removed pixel grid controls (cell size slider, color pickers) — cell size is now scroll/pinch only; colors are fixed.
  • Moved info bar to a floating HUD overlay above the canvas.
  • Added Escape key support to close all modals.
  • Added npm run dev workflow with nodemon for local development.
v1.3
Spanish glyphs + canvas polish
2026-05-08
  • Added Spanish accented letters and punctuation across the glyph set.
  • Improved canvas interaction with smoother scroll and hover behavior.
  • Expanded symbols and punctuation coverage from related glyph updates.
v1.2
Filename input + accessibility
2026-04-26
  • Added editable PNG filename input with auto-populated slugified defaults.
  • Improved accessibility and visual contrast across the control panel.
  • Added favicon, about modal, footer attribution, and visible version label.
  • Documented filename-input design and implementation details.
